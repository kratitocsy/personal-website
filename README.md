# aryansengar.wynko.in

Personal website of Aryan Singh Sengar. Plain HTML/CSS/JS, no build step. Deployed on Vercel from `main`.

- `index.html` – homepage (About, Experience, Projects, Story)
- `resume.html` – printable résumé (Print / Save PDF button)
- `assets/css/` – styles; `assets/js/main.js` – spotlight, active nav, time-travel dialog
- `assets/img/` and `assets/maglion-*` – project images

All content comes from Aryan's CV and the Maglion pitch deck. Keep claims accurate: Maglion is tested by simulation only and not yet built.
